# Permutation Promenade

An interactive presentation on why the dance in [Advent of Code 2017, day 16](https://adventofcode.com/2017/day/16) repeats after so few rounds, even though 16 dancers can be arranged in 20,922,789,888,000 ways.

It's a [marimo](https://marimo.io) notebook exported to WebAssembly, so it runs entirely in your browser. The first load takes a little while to download Python.

The default dance is randomly generated. Pick "paste a puzzle input" in the first slide's dropdown to explore your own.

To run it locally instead: `uvx marimo run --sandbox permutations.py`
